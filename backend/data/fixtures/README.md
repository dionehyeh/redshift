# Backend Data Fixtures

This directory holds pre-downloaded, validated fixture data for offline execution and fast testing under `DEMO_MODE=1`:
- `cell_09.5N_076.5E_normals.parquet`: 52-week normals for the Kerala demonstration site.
- `cell_09.5N_076.5E_weekly.parquet`: 20-year weekly historical weather series.
- `season_loss.parquet`: Weekly weather and NDVI series for the paddy crop failure season.
- `soil_estimate.json`: ISRIC SoilGrids pH and texture fixture.
- `dem_window.npy`: 33x33 SRTM DEM elevation grid surrounding the demo farm.
